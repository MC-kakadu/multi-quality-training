## 🚀 Quick Start
1) Login to Google Colab environment (A100 GPU 40GB RAM)
2) Copy and paste Python files in the "scripts" folder into each cell in order of number
3) Upload raw data file to your Google Drive folder (ex. VisDrone_datasets)
4) Connect Google Drive to your colab file
5) Set up and verify the path in the code
6) Run each cell's code in order
7) You can check and download the results

## ⚠️ Important Implementation Notes
1) Degradation simulation: resolution downsampling + JPEG compression (jointly applied)
Each of the five quality levels (Q20–Q100) is generated by (1) downsampling and upsampling the image (bicubic) to approximate resolution loss, followed by (2) JPEG re-encoding at a quality factor mapped to the same level. Both mechanisms are applied together for every quality level, including Q100 (which uses JPEG quality 100 with no resolution change) — this is deliberate, and JPEG re-encoding a Q100 image will still show a finite (not infinite) PSNR relative to the source, which is expected.
2) The "Highest Performance Epoch" reported in the paper's tables is selected by Ultralytics' internal fitness score:
```
fitness = 0.1 × mAP50 + 0.9 × mAP50-95
```
not by mAP50 alone. Using mAP50 alone to identify the best epoch from results.csv will, in some cases, select a different epoch than the one Ultralytics actually saved as best.pt. scripts/extract_best_epoch.py implements the correct fitness-based selection and includes a validation check against Ultralytics' own logged best-epoch value.

### Hyperparameters
All experiments (Standard, Multi-Quality, B1/B2/B3, and both additional architectures) use identical hyperparameters; the only varying factor is the training data configuration, to isolate the effect of quality-level design from confounding training variables.

| Parameter | Value |
|-----------|-------|
| Input Size | 640×640 |
| Batch Size | 48 |
| Initial LR (lr0) | 0.06 |
| Optimizer | SGD (momentum=0.9) |
| Weight Decay | 0.0005 |
| Training Epochs | 100 (early stopping; patient 50) |
| Warmup Epochs | 3 |
| Warmup Momentum | 0.8 |
| Warmup bias Learning Rate | 0.1 |
| Workers | 8 |
| Random Seed | 42 |
| Mixed Precision | Enabled (AMP) |
